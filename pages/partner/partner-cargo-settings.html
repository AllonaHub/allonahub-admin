Allona Partner Panele Dön

Kargo Ayarları

Varsayılan kargo firmanızı seçin. API Key, API Secret ve teknik entegrasyon bilgileri partnerlere gösterilmez; bu bilgiler AllonaHub admin sistemi tarafından yönetilir.

Kargo Akışı

Partner siparişi sadece onaylar. Sipariş hazırlanıyor durumuna geçer. Kargo takip numarası ve kargo hareketleri ileride AllonaHub backend/kargo API entegrasyonu ile otomatik yönetilecektir.
